# Первый прототип

Windows x64, .NET 8 / WPF. Экспериментальная неподписанная сборка, ещё не проверена на реальном ПК.

## Получение
После коммита откройте Actions → Build Windows launcher → успешный запуск → Artifacts → SteamConsoleLauncher-win-x64. Распакуйте весь архив и запустите Launcher.exe. Среда .NET включена в публикацию. Если сборка завершилась ошибкой, исполняемый файл не готов.

## Реализовано в исходниках
- Поиск Steam через реестр текущего пользователя и стандартную папку.
- Чтение libraryfolders.vdf и appmanifest_*.acf, включая дополнительные диски.
- Список приложений с флагом установленного содержимого; инструменты и демоверсии могут также попасть в список.
- Поиск по названию, запуск через steam://rungameid, внешняя страница магазина.
- F11: полный экран, Escape: выход из полноэкранного режима.

## Пока отсутствует
Обложки и точное соответствие визуальному макету, управление геймпадом, импорт всей библиотеки аккаунта, установка игр, трейлеры, скриншоты, отзывы, собственная витрина, обновления и подпись кода. Не вводите пароль или API-ключ Steam: прототип их не запрашивает. Запуск не отслеживает завершение игры и не скрывает оболочку автоматически.

Это техническая основа проверки Steam и облачной сборки, а не законченный интерфейс с концепт-изображения. Для запуска игр требуется установленный Steam и доступ к соответствующей игре.
