# Native content candidate
This commit adds source modules and applies tools/Apply-NativeContent.ps1 to the cloud checkout before compilation. Repository Program.cs is the untransformed base; run the same script once before local builds. The script never pushes commits. It connects NativeDetails, transitions and audio, and names the assembly _launcher.
Extract the whole artifact and run _launcher.exe, not the source ZIP. Windows compilation and runtime tests are pending.
Includes public Steam descriptions/facts, screenshots, direct MP4 videos, up to 10 Russian reviews via GetAppReviews, metadata/review cache, original synthesized UI tones and saved volume/reduced-motion preferences. Account import and cover/hero fallback cache remain from the base version.
Not a finished redesign of the whole library. Appdetails is internal and may change. HLS/DASH unsupported, no image disk cache for screenshots, metadata may use stale cached fallback, fixed details height needs resize testing, missing media is possible. Gallery controls are focusable but full gamepad acceptance testing is pending. Web checkout still requires separate authentication and mouse/keyboard for forms. Large-library virtualization is not implemented. No promise of completed payment integration or all-controller compatibility.
