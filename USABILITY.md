# Usability fixes — untested source candidate
Cloud build applies NativeContent, ConsoleUX, then Usability transforms. Repository base source is transformed in the checkout, never committed by the scripts.
Changes: common rounded button template for shell and native details, distinct active-tab tag and keyboard focus outline, description renderer preserving common headings/paragraphs/list bullets/bold/italic without executing HTML, right-stick scrolling via SDL axis 3, explicit mouse-wheel scrolling on details, left/right gallery stepping, no repeated ItemsPanel rebuild for unchanged home/library mode.
Runtime tests still pending. Focus loss may have multiple causes: preventing panel rebuild addresses an identified cause but is not a proven complete fix. Renderer handles common HTML tags, not arbitrary full HTML/CSS; ordered lists currently use bullets. Store remains the existing WebView; this commit does NOT implement the native store/catalog or solve Steam web authentication. NativeDetails still uses a long scroll layout rather than the planned full tabbed design. Forms/settings and media formats retain earlier limitations. New controller codes 101/102 are internal scroll actions. The embedded web store does not yet handle right-stick scrolling in this patch. No success/performance claim before build and device tests.
