# Console home — first visual pass, untested candidate
Cloud build applies Apply-NativeContent.ps1 then Apply-ConsoleUX.ps1. Program.cs remains the base, ConsoleUX.cs is a partial class integrated before compilation. No automatic commits are made by these scripts.
Changes: startup borderless fullscreen, whole-window backdrop, horizontal installed-game strip on home, grid-only library, search/filter hidden on home, service actions in a menu, larger heading, animated selected-card scale, contextual application controls, generated original blue play icon, existing _launcher.exe output retained. Home is installed games, not claimed recent-play history. This is NOT the final redesign of NativeDetails, whose sections still need tabbed presentation. Audio/motion preferences remain available from menu.
Game return is experimental: watches Steam RunningAppID and per-app Running registry hints. Does not track the short-lived steam:// process. Minimizes only after a running signal is observed; waits at least 15 seconds from observation and four stopped polls before restore. If no signal appears within 180 seconds, stops watching without minimizing. If another Steam app is running, stops without forcing foreground. Registry hints are not a guaranteed public Steam API and may be missing or stale. No universal process-tree session tracking yet. Windows may deny activation: restore and foreground attempts are not a guarantee of focus. No permanent Topmost or synthetic keyboard input.
Pending tests: compile, icon visibility, true fullscreen, home scroll and focus, large library performance, 8BitDo/Xbox/other SDL controllers, game start/exit/crash, switching to other applications. Default hints still use Xbox-style labels, remapped A/B hints are not yet dynamic. Small-screen navigation may need sizing work. Grid virtualization and complete on-screen keyboard are not implemented. This update is not declared tested or release-ready.
