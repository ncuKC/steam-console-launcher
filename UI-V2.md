# UI v2 — экспериментальная версия
Новый интерфейс: фон выбранной игры, обложки, отдельные режимы главной и библиотеки, поиск, фильтры. Главная показывает установленные игры; библиотека — объединение импорта аккаунта и установленных.
Импорт: в приложении введите SteamID64 и личный Steam Web API key. Никогда не отправляйте ключ в чат или GitHub. Ключ используется только для HTTPS-запроса к api.steampowered.com и не записывается на диск. Пароль Steam не используется. Настройки приватности могут блокировать получение списка. Кеш коллекции (названия и appid) хранится в LocalAppData/SteamConsoleLauncher/library.json. Чтобы удалить импорт, удалите этот файл; только один импортированный аккаунт за раз.
Обновить перечитывает локальные установки и кеш, а не синхронизирует аккаунт. Для синхронизации повторите импорт. Нулевой ответ не считается пустой библиотекой без game_count.
Изображения загружаются по сети с CDN Steam; некоторые могут отсутствовать. Дисковый кеш изображений и виртуализация сетки пока не реализованы, поэтому производительность на больших библиотеках требует проверки. При отсутствии обложки остаётся название.
Геймпад, отзывы, видео, автоматическое возвращение после игры и встроенная оплата отсутствуют. Стандартный ComboBox и системная рамка окна пока сохранены. F11 переключает полноэкранный режим. Служебное приложение 228980 скрыто.
Сборка и работа нового интерфейса пока не проверены; успешный workflow подтверждает только сборку, не функциональное тестирование.
