# Журнал изменений

## Новая оболочка

- Магазин открывается внутри общей оболочки.
- LB/RB переключают главные вкладки, LT/RT — подвкладки магазина и карточки игры.
- «Желаемое» работает через новый API Steam.
- Названия игр в магазине переносятся на две строки.
- Подсказки кнопок показывают реальные обозначения геймпада.
- Обновления лаунчера ставятся из меню, с индикатором загрузки.

## Внутреннее

- Правки из Apply-*.ps1 перенесены в исходники, скрипты удалены.

Не проверено на устройстве.
