# Журнал изменений

## Аккаунт Steam

- После входа в Steam (в том числе по QR-коду) в меню появилась кнопка «Импортировать игры из аккаунта»: список игр загружается из сессии входа, без SteamID64 и ключа API. Если Steam список не отдал, остаётся прежний ручной импорт через «Аккаунт».

## Геймпад

- Удержание крестовины повторяет шаг: задержка 400 мс, затем каждые 110 мс.

## Новая оболочка

- Магазин открывается внутри общей оболочки.
- LB/RB переключают главные вкладки, LT/RT — подвкладки магазина и карточки игры.
- «Желаемое» работает через новый API Steam.
- Названия игр в магазине переносятся на две строки.
- Подсказки кнопок показывают реальные обозначения геймпада.
- Обновления лаунчера ставятся из меню, с индикатором загрузки.

## Внутреннее

- Правки из Apply-*.ps1 перенесены в исходники, скрипты удалены.
- Коды кнопок геймпада вынесены в именованные константы (PadButton).

Не проверено на устройстве.
